# Проект «Природа» (АИС ЕГФДЭМ / ГИС «Экология города»)

**Роль:** Системный аналитик

**Домен:** GovTech, Экологический мониторинг, Геоинформационные системы (ГИС)

## 📝 Описание проекта
Развитие автоматизированной информационной системы для сбора, обработки и визуализации данных экологического мониторинга (атмосфера, вода, почвы, зеленые насаждения). Система агрегирует данные из десятков источников и предоставляет аналитикам и ведомствам единую картину состояния окружающей среды.

[Результат «Экологическая ситуация города Москвы»](https://mosecom.mos.ru/)

## 🎯 Мои задачи и зона ответственности

В рамках проекта я отвечал за проектирование интеграций, моделирование данных, разработку нормативно-справочной информации (НСИ) и подготовку полного пакета документации.

### 1. Интеграции и API
- Описал взаимодействие с микросервисами(система ЕГРН).
- Разработал контракты API (REST/HTTP, JSON) для таблицы запросов ДГИ Москвы.
- Спроектировал логику синхронизации НСИ с внешними системами в части кадастровых номеров и адресного реестра.
- Проводил сравнительный анализ данных (Prod/Dev), документировал расхождения и валидировал ответы сервисов.

### 2. Моделирование данных и миграция
- Спроектировал логические и физические схемы БД (ER-диаграммы) для учета данных о выбросах в атмосферу, водных объектах, почвах и химических элементах (РДК).
- Участвовал в разработке правил маппинга и написал SQL-запросы для миграции исторических данных из legacy-систем.
- Написал SQL-запросы для проверки и валидации загруженных данных (водные объекты, створы, показатели).

### 3. Проектирование НСИ и личных кабинетов (ЛК)
- Разработал концепцию Личных кабинетов (ЛК) в разрезе подсистем для ведения источников данных, сущностей и параметров измерений.
- Описал требования к ведению сложных справочников: водные объекты, почвы, зеленые насаждения, противогололедные реагенты, метеоусловия, приборы экомониторинга.
- Проработал ролевую модель и разграничение прав доступа пользователей.

### 4. Отчетность и документация
- Участвовал в доработке ЧТЗ на разработку отчетов для подсистем АСКЗА (контроль атмосферы), бюллетеней, отчетов по промышленным выбросам.
- Описал шаблоны протоколов для Аналитической лаборатории.
- Участвовал в разработке ПМИ по описанию методик проверок для 5 подсистем.
- Создал часть Руководства пользователя и описал схемы данных.
- Проработал функционал кнопки «Утверждение», журналов действий и модулей «Историзма».
