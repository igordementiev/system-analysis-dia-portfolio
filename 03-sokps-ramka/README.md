# Система объективного контроля «СОКПС Рамка» (IoT + ML)

**Роль:** Ведущий системный аналитик (с элементами архитектора и продуктового аналитика)
**Домен:** Транспорт, IoT, Машинное обучение (ML), Компьютерное зрение (CV)
**Контекст:** Аппаратно-программный комплекс для мониторинга состояния вагонов метро (серия «Ока»).

## 📝 Описание проекта
Аппаратно-программный комплекс (IoT + ML) для мониторинга состояния вагонов метро с использованием тепловизоров и видеокамер. Система автоматически распознает номера вагонов, контролирует нагрев узлов (буксы, редукторы, ТЭД, муфты) и оповещает оператора об аномалиях через веб-интерфейс.

## 🎯 Мои задачи и зона ответственности

Проект велся в несколько этапов, от проектирования архитектуры и ML-пайплайна до рефакторинга и сдачи в промышленную эксплуатацию.

### 1. Сбор требований и проектная документация
- Разработал функциональные требования (ФТ) и Технические задания (ТЗ) на ПО СОКПС.
- Разработал Программу и Методику Испытаний (ПМИ), создал матрицу трассировки требований (соотношение задач и ТЗ).
- Написал полный пакет эксплуатационной документации: Паспорт системы, Руководство пользователя, Руководство администратора, инструкции по деплою и настройке SSL.

### 2. Проектирование интеграций и архитектуры
- Спроектировал отказоустойчивую интеграцию ML-сервера (Edge-вычисления на базе **NVIDIA Tesla T4**) и SCADA-сервера через **MQ-очереди** (Message Queue) и **Stream API** для передачи медиафайлов (**S3/Minio**).
- Описал микросервисную архитектуру ML-модуля (Event Bus, Go2RTC, Watchdog для автоматического восстановления).
- Разработал контракты **REST API** и **WebSocket** (для real-time обновлений UI), ведение документации в Swagger/OpenAPI.

### 3. Моделирование данных и бизнес-логики
- Формализовал математическую логику: расчет дельты температур (ΔT), пороговые значения для 5 зон контроля и алгоритмы цветовой индикации (Green/Red/Gray).
- Спроектировал JSON-схемы для обмена данными между нейросетями, бэкендом и фронтендом.
- Описал логику работы компьютерного зрения (OCR-распознавание номеров, детекция прихода/ухода поезда, определение загрязнения камер).

### 4. Проектирование UI/UX
- Создал интерактивные макеты в **Figma** (окно оборудования, детальная информация, отчетность, журнал событий, фильтры, навигация).
- Проработал экраны визуализации аномалий на схеме тележки вагона с цветовой подсветкой неисправных узлов.

### 5. Модернизация и поддержка
- Провел рефакторинг данных: группировка оборудования (Редуктор, Зубчатая муфта, ТЭД) с обновлением структуры БД и контрактов API.
- Настроил работу FE-части через публичный IP, установка SSL-сертификата.
- Провел оценку трудозатрат (до 343 ч/ч) и написал Задания на выполнение работ (SOW).
