# Предпроектное обследование и миграция legacy-логики (JTI)

**Роль:** Системный аналитик (Pre-sale)
**Домен:** FMCG, Supply Chain, Планирование производства и запасов (NTM, CSMS, Tobacco, Movement)
**Заказчик:** Japan Tobacco International (JTI)

## 📝 Описание проекта
Проведение предпроектного обследования (Pre-sale) с целью оценки возможности и стоимости миграции сложной legacy-логики (Excel/VBA) в современный контур SAP / 1C / BI. Проект затрагивал процессы планирования производства и запасов.

## 🎯 Мои задачи и зона ответственности

### 1. Анализ предоставленной документации
- Провел глубокий анализ вводных данных и документации, предоставленных РП и аналитиками 1С, для понимания специфики процессов планирования (NTM, Tobacco, CSMS).

### 2. Реверс-инжиниринг legacy-систем
- Выполнил разбор текущей логики в **Excel и VBA** (включая сложную логику замещения Substitution).
- Провел инвентаризацию **22 макросов** и выявил «узкие места» текущих процессов.

### 3. Подготовка итоговой документации
- На основе проведенного анализа сформировал документ **«ФТ по оптимизации БП»**, где описал требования к целевой архитектуре, правила миграции данных из Excel в 1C и BI, а также регламенты работы с новыми процессами для РП.

### 4. Оценка трудозатрат (PERT)
- Разработал детальную оценку проекта с разбивкой по **6 этапам** и **4 ролям** (БА, CA 1C, Data-аналитик, Excel-специалист).
- Рассчитал сроки и стоимость работ, обосновав необходимость перехода с Excel на 1C/BI.

### 5. Методологическая поддержка
- Оказал помощь аналитикам 1C (не обладающим глубокой экспертизой в бизнес-анализе) в разборе бизнес-логики и подготовке данных для интеграции с **SAP** (транзакции CA01, CR01, ZCS11N).

## 🧰 Стек и инструменты
`Excel/VBA`, `SAP`, `1C`, `BI`, `PERT`, `Supply Chain`, `Business Analysis`, `Confluence`
