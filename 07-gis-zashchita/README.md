# ГИС «Защита» (Государственная информационная система безопасности объектов города Москвы)

**Роль:** Системный аналитик
**Домен:** GovTech, Антитеррористическая защищенность (АТЗ), ГИС

## 📝 Описание проекта
Развитие Государственной информационной системы безопасности объектов города Москвы (1 и 2 очереди). Система предназначена для автоматизации процессов обеспечения антитеррористической защищенности объектов, ведения карточек безопасности и работы межведомственных комиссий.

## 🎯 Мои задачи и зона ответственности

### 1. Онбординг и реверс-инжиниринг
- Провел онбординг в сложный legacy-проект и реверс-инжиниринг архитектуры для актуализации проектной документации (Пояснительных записок, Руководств пользователя и администратора) на основе существующих наработок команды.

### 2. Анализ нормативной базы и требований
- Изучил и структурировал требования второй очереди системы (ЧТЗ на создание функциональности) в части автоматизации процессов формирования Межведомственных комиссий (МВК) и заполнения Карточек объектов.
- Обеспечил соответствие логики системы требованиям актуальных Постановлений Правительства РФ в сфере АТЗ.

### 3. Описание архитектуры и подсистем
- Задокументировал прикладную и технологическую архитектуру, включая подсистемы «Картография», «Чат-бот», «Паспорт безопасности объекта», «Мониторинг и администрирование».
- Описал интеграционное взаимодействие с внешними системами (АИС ЕКС, СУДИР, РТ Sandbox).

### 4. Разработка API-контрактов
- Спроектировал и описал контракты **REST API** для интеграционного взаимодействия: методы `PATCH` (изменение статуса отображения камер), `DELETE` (удаление проекта камер), `POST` (старт валидации, создание сессии загрузки).
- Описал логику работы слушателей очередей (`ct-map-import-service`) для импорта данных.

### 5. Соблюдение стандартов
- Оформил документацию в строгом соответствии с **ГОСТ** и требованиями Департамента информационных технологий города Москвы (ДИТ) для успешной сдачи этапов Государственного контракта.

## 🧰 Стек и инструменты
`REST API`, `JSON`, `ГОСТ`, `АТЗ`, `Reverse Engineering`, `Jira`, `Confluence`
