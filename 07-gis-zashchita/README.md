# ГИС «Защита» (Государственная информационная система безопасности объектов города Москвы)

**Роль:** Системный аналитик

**Домен:** GovTech, Антитеррористическая защищенность (АТЗ), ГИС

## 📝 Описание проекта
Развитие Государственной информационной системы безопасности объектов города Москвы. Система предназначена для автоматизации процессов обеспечения антитеррористической защищенности объектов, ведения карточек безопасности и работы межведомственных комиссий.

## 🎯 Мои задачи и зона ответственности

### 1. Онбординг и реверс-инжиниринг
- Провел онбординг в сложный legacy-проект и реверс-инжиниринг архитектуры для актуализации проектной документации на основе существующих наработок команды.

### 2. Анализ нормативной базы и требований
- Изучил и структурировал требования второй очереди системы в части автоматизации процессов формирования Межведомственных комиссий и заполнения Карточек объектов.
- Обеспечил соответствие логики системы требованиям актуальных Постановлений Правительства РФ в сфере АТЗ.

### 3. Описание архитектуры и подсистем
- Задокументировал прикладную и технологическую архитектуру, включая подсистемы «Картография», «Чат-бот», «Паспорт безопасности объекта», «Мониторинг и администрирование».
- Описал интеграционное взаимодействие с внешними системами.

### 4. Разработка API-контрактов
- Спроектировал и описал контракты **REST API** для интеграционного взаимодействия.
- Описал логику работы слушателей очередей для импорта данных.

## 🧰 Стек и инструменты
`REST API`, `JSON`, `ГОСТ`, `АТЗ`, `Reverse Engineering`, `Jira`, `Confluence`
